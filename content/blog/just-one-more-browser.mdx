# The tabs made me do it

I didn’t mean to become a browser nomad. Like most people, I started with Chrome and figured that was the end of it. It came (effectively) pre-installed, it worked, and it fitted a lot of my needs for a while.

But then things started to shift — not in any grand or dramatic way, but through a slow build-up of minor annoyances. Watching 1080p60 videos at 2x speed on YouTube started dropping frames on my laptop that was supposed to be good (one of the first adopters of the Ryzen laptop CPUs here 👋). That was my first real "why is this happening?" and "could this be better?" moment with a browser. And once you start noticing those cracks, it’s hard to unsee them.

What followed was a series of hopeful installs, temporary highs, and inevitable disappointments. Opera GX was flashy and weirdly fixed my video issues. Arc felt like a breath of fresh air with actual ideas about how browsers should work — until it didn’t. Zen was lightweight and open source, but Firefox’s quirks made it harder to stick with. And now there’s Dia, the spiritual successor to Arc, which is beautiful but feels like it’s solving a different problem than the one I have.

This blog is a walk through that whole journey — why I switched, what I liked, what started to break down, and what I’ve learned about how I use browsers. I’m not here to declare a winner or pretend I’ve found “the one.” In fact, I still haven't found the one and I'm still looking. But if you’ve ever installed a new browser because a YouTube sponsorship caught you in a moment of weakness, or you saw all the tech people start using this newfangled browser which is all the rage, this blog might resonate with you.

## The browser you already have
- Chrome
- Pretty much the default but I ran into issues with the performance of the browser somehow

## A gamer’s Browser, apparently
- Was good, fixed mu issues somehow
- Ended up getting slower and slower as more useless features were added
- Startup time became abyslman

## Performance, profiles, and pretending it’s new
- Tried chrome again and it felt so much more snappy
- Continued to use this for a while
- Started to get into some good productivity flows
- Tab groups + tab sync
- Different workspaces (profiles)
- Was pretty good
- This is when it went off the rails though

## Built for the few, not the funnel


- Heard a lot about the browser in the developer community
- Got beta access for the Windows beta as I wasn't on MacOS
- Was really good, bit rough at the start but the vertical tabs were amazing
- Pinned tab groups were great
- Arc sync was great
- Live folders were amazing as a developer as I could immediately know when I was needed for review
- Different workspaces worked as well
- Essential tabs were good
- Popout window for videos was so helpful
- Tried out the MacOS version on a work MacBook as I was doing a lot of development for iOS there
- So much better than Windows so I got a bit disillusioned as I wanted the features MacOS had
- The Browser Company decides to stop development of Arc and build Arc 2.0 (which was supposed to be built on Arc but never came)
- Again the browser began to feel slow
- I do a lot of local development, so I'd paste in localhost:6001 into the new tab menu, but it just became too slow
- I would do new tab and enter before it registers it's a link so I would end up Googling local host again and again


## Arc’s soul, Firefox’s baggage
- A firefox open-source browser
- Vertical tabs
- Essential tabs
- Basically Arc but Firefox
- Main issue is it feels unpolished
- Firefox containers are not as good as Chrome workspaces
- Plugins persist across all workspaces, which is annoying for a personal and work one
- Tab sync was worse than Arc
- I like it, I like the direction, but I want a very polished experience, like Arc but being supported

## Beautiful, but it’s not Arc
- This is what Arc was abandoned for
- Got Alpha access, and now that I'm on a MacOS laptop for work I was able to use it
- It feels really nice
- Doesn't have tabs
- Workspaces are good but the switcher at the moment is annoying as it makes multiple tabs
- The inbuilt AI chat is pretty nice, mentioning tabs is veyr useful - especially for sites that don't let robots read them
- Just really miss my vertical tabs
- Good news is that they are bringing some more features from Arc over, so hopefully we get something similar to Arc
- E.g. tab sync, optional vertical tabs, live folders

## Where am I going next
- Will continue with Dia for a bit, but I do long for my vertical tabs
- Maybe I'll switch back to Arc for a bit, as it is better on MacOS but my home computer is still Windows
- Does anyone have any browser suggestions I should try?
